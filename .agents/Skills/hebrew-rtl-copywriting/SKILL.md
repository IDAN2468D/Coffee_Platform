# Hebrew Coffee Copywriting Skill

## Copywriting Principles
- **Tone:** Premium, sensory, inviting, gourmet, reassuring, and energetic.
- **Key Terms:** קלייה טרייה, 100% ערביקה גורמה, מנות אספרסו, חלב שיבולת שועל, ערכת חליטה V60, קפסולות אלומיניום.
- **RTL Layout Rules:**
  - Always enforce `dir="rtl"` on root container elements.
  - Use logical Tailwind spacing (`ms-*`, `me-*`) or explicit `rtl:` modifiers.
  - Format prices with ILS currency symbol on the right (e.g., ₪22).
