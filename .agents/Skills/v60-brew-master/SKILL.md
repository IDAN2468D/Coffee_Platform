# V60 Brew Master Skill

## Brewing Parameters
- **Ratio:** 1:15 (15g coffee to 225g water).
- **Water Temperature:** 92°C - 94°C.
- **Bloom Phase:** 0 - 45s (50g water pour).
- **Total Brew Time:** 2:30 minutes.
