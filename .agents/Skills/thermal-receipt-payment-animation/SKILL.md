# Thermal Receipt Payment Animation

## Instructions

### Step 1: Choose Your Stack and Scaffold

Decide which target you are building for before writing any code. The component
tree and animation APIs differ significantly.

| Target | Libraries | Command |
|--------|-----------|---------|
| Next.js (web) | Tailwind CSS, Framer Motion | `npx create-next-app@latest --tailwind` then `npm i framer-motion` |
| Expo (React Native) | NativeWind, Reanimated 3, react-native-confetti-cannon | `npx create-expo-app` then `npm i react-native-reanimated nativewind react-native-confetti-cannon` |

For the web path, all code in Steps 2-6 targets React + Framer Motion.
For the native path, substitute `Animated.View` from Reanimated 3 and
`ConfettiCannon` from react-native-confetti-cannon.

The rest of this skill walks the web path in detail, then notes native
adaptations in each step.

### Step 2: Build the Printer Chassis Component

Create `components/PrinterChassis.tsx`. The chassis is a fixed-size dark block
with a horizontal slot at the bottom. The slot uses `overflow: hidden` so the
receipt starts hidden.

Key Tailwind classes for the chassis:

- Background: `bg-[#0F172A]`
- Rounded top corners only: `rounded-t-3xl`
- Inner shadow on the slot: apply `box-shadow: inset 0 4px 12px rgba(0,0,0,0.6)` via a Tailwind arbitrary value or a `style` prop
- Slot height: `h-6` (24px), full width

Status LED: a `w-3 h-3 rounded-full bg-emerald-400` div positioned top-right,
wrapped in a Framer Motion component with an `animate` prop cycling opacity
between 0.4 and 1.0 on a 1.2s repeat.

```tsx
// LED pulse (Framer Motion)
<motion.div
  className="w-3 h-3 rounded-full bg-emerald-400"
  animate={{ opacity: [0.4, 1, 0.4] }}
  transition={{ duration: 1.2, repeat: Infinity, ease: "easeInOut" }}
/>
```

Native adaptation: use `useSharedValue` + `withRepeat` + `withTiming` from
Reanimated 3 to drive the opacity on an `Animated.View`.

### Step 3: Build the Receipt Paper Component

Create `components/Receipt.tsx`. The receipt is an `#F8FAFC` card that renders
inside the slot's `overflow: hidden` container.

Serrated edges: use an SVG `clipPath` or a repeating CSS mask with a zigzag
pattern. A practical shortcut is an inline SVG edge at the top and bottom of
the receipt rendered as `<img>` or `<svg>` tags with a sawtooth path. Example
SVG path for one edge (12px teeth, 6px deep):

```
M0,0 L6,6 L12,0 L18,6 L24,0 ... (repeat to full width)
```

Elevation shadow: `shadow-[0_8px_32px_rgba(0,0,0,0.18)]`

Content hierarchy inside the receipt (top to bottom):

1. Merchant logo placeholder (`<img>` or `next/image`, centered)
2. Merchant title (`text-sm font-bold text-center`)
3. Address subtext (`text-xs text-gray-400 text-center`)
4. Horizontal rule (dashed, `border-dashed border-gray-200`)
5. Two-column row: Order ID (left, `text-xs text-gray-500`) + Amount (right, `text-lg font-bold`)
6. Two-column row: Date/time (left) + Status badge (right, see Step 4)
7. Payment method row: icon + masked number (`•••• 9012`)
8. Barcode/QR block: use a library like `qrcode.react` for the QR, or a static SVG barcode for demo purposes

### Step 4: Animate the Receipt Dispense

Wrap the receipt in a `motion.div` inside the slot container. Drive the
dispense with a `translateY` variant.

```tsx
const dispenseVariants = {
  hidden: { y: "-100%" },
  visible: {
    y: "0%",
    transition: {
      duration: 1.1,
      ease: [0.22, 1, 0.36, 1],      // custom spring-like cubic bezier
      delay: 0,
    },
  },
};
```

The rebound (soft bounce) is embedded in the cubic bezier. If you prefer a
true spring, replace `ease` with `type: "spring", stiffness: 80, damping: 12`.

Trigger: call `controls.start("visible")` from a `useAnimationControls()` hook
when the user clicks the replay button or when the component mounts.

Native adaptation: use `useSharedValue(SLOT_HEIGHT)` for the Y offset, then
`withSpring(0, { stiffness: 80, damping: 12 })` from Reanimated 3.

### Step 5: Animate the Status Badge and Confetti

**Status badge** (renders inside the receipt, Step 3 row 6):

```tsx
const badgeVariants = {
  hidden: { scale: 0.85, opacity: 0 },
  visible: {
    scale: [0.85, 1.05, 1],
    opacity: 1,
    transition: { delay: 1.1, duration: 0.3, ease: "easeOut" },
  },
};
```

Badge markup: `bg-emerald-100 text-emerald-700 text-xs font-semibold px-2 py-0.5 rounded-full`
with text "Paid in Full".

**Confetti explosion** (0.7s after dispense starts):

For web, use the `canvas-confetti` npm package. Call it from a `useEffect`
after a 700ms timeout when the animation triggers:

```tsx
import confetti from "canvas-confetti";

const triggerConfetti = () => {
  setTimeout(() => {
    confetti({
      particleCount: 80,
      spread: 70,
      origin: { x: 0.5, y: 0.45 },   // aim at the slot
      colors: ["#10B981", "#F8FAFC", "#6366F1", "#F59E0B"],
      gravity: 1.2,
      ticks: 180,
    });
  }, 700);
};
```

Native adaptation: fire `ConfettiCannon` from `react-native-confetti-cannon`
at `autoStart={false}`, calling `cannon.current.start()` via a ref after the
700ms delay.

### Step 6: Wire Up the Replay Trigger

Add a replay button below the printer chassis. On click:

1. Reset receipt to `hidden` state immediately.
2. Clear confetti canvas (call `confetti.reset()` for the web package).
3. After a 100ms tick (so React re-renders the reset), call `controls.start("visible")` and `triggerConfetti()`.

```tsx
const handleReplay = async () => {
  controls.set("hidden");
  confetti.reset();
  await new Promise(r => setTimeout(r, 100));
  controls.start("visible");
  triggerConfetti();
};
```

Replay button styling: `mt-6 px-4 py-2 rounded-full bg-slate-800 text-white text-sm font-medium hover:bg-slate-700 transition-colors`

### Step 7: Responsive Layout

Wrap the entire assembly in a centered flex column:

```
flex flex-col items-center justify-center min-h-screen bg-slate-100 p-4
```

Printer chassis width: `w-72 sm:w-80` (288px on mobile, 320px on small screens).
Receipt width: 100% of the chassis width minus 2px on each side for the slot
margin.

Use `max-w-sm mx-auto` on any wrapping container to prevent the printer from
stretching on wide viewports.

### Step 8: QR Code and Barcode

For the QR block, install `qrcode.react`:

```
npm i qrcode.react
```

Render:

```tsx
import { QRCodeSVG } from "qrcode.react";
<QRCodeSVG value="https://your-verify-url.com/tx/123456" [verify] size={80} />
<p className="text-[10px] text-gray-400 mt-1 tracking-widest">SCAN TO VERIFY</p>
```

For a barcode, use `react-barcode` or render a static SVG for demo purposes.
The barcode and QR are purely decorative in the animation; they do not need to
encode real payment data.

## Gotchas

- **`overflow: hidden` on the slot is mandatory.** If you apply `overflow: hidden`
  to the wrong ancestor (e.g., the page wrapper), the receipt will be clipped
  globally. Apply it only to the narrow slot `div` directly inside the chassis,
  not to the chassis itself or any outer container.

- **Framer Motion `y` percentage values are relative to the element's own
  height.** Setting `y: "-100%"` moves the receipt up by exactly its own height,
  which is what you want. If you use a pixel value instead (e.g., `y: -300`),
  the receipt will not fully hide on different screen sizes or when the content
  changes length.

- **`canvas-confetti` fires on the global canvas.** If your page has a custom
  `<canvas>` element, confetti may render behind or over it. Pass a `canvas`
  option to `confetti.create(myCanvas)` to target a dedicated element, or use
  `zIndex` carefully.

- **React Native `overflow: hidden` is not `visible` by default on Android.**
  On iOS, `overflow: hidden` on a `View` clips children as expected. On Android,
  you may need to wrap the slot in an additional `View` with `elevation: 0` to
  force correct clipping. Test on a real device, not just the emulator.

- **Serrated edge SVG width must match the receipt width exactly.** If the SVG
  viewBox width does not match the rendered container width, the teeth will
  either tile awkwardly or leave a gap. Use `preserveAspectRatio="none"` with
  `width="100%"` on the SVG element so it stretches to fill.

- **Replay state reset must happen before `controls.start("visible")`** or
  Framer Motion will animate from the current (already visible) position and
  the dispense will not be visible. Use `controls.set("hidden")` (synchronous)
  before the 100ms delay.

- **QR codes encoding real payment data.** If this component is used in
  production, do not encode raw card numbers, CVVs, or PAN data in the QR
  value. Encode only a transaction reference ID that resolves server-side.

## Troubleshooting

### Receipt is visible above the slot before the animation starts

Cause: The wrapping slot container does not have `overflow: hidden`, or the
receipt's initial `y` value is not `-100%`.
Solution: Confirm the slot `div` has `overflow-hidden` (Tailwind) or
`style={{ overflow: "hidden" }}` (inline). Confirm `initial={{ y: "-100%" }}`
is set on the `motion.div` wrapping the receipt content.

### Confetti fires but appears behind the printer chassis

Cause: `canvas-confetti` uses a full-page canvas at `z-index: 0` by default.
The chassis may have a higher stacking context.
Solution: Call `confetti.create()` with a dedicated canvas element positioned
above the chassis, or set the chassis's `z-index` to a known value and pass
`zIndex` to the confetti canvas explicitly.

### Badge pop animation does not play

Cause: The `delay: 1.1` on the badge variant is only correct if the dispense
starts at `t=0`. If `controls.start("visible")` is called later (e.g., inside
a `useEffect` with a dependency), the badge delay is relative to that call.
Solution: Ensure the badge is also controlled by the same `controls` object,
or use a separate `useAnimationControls()` for the badge and call
`badgeControls.start("visible")` inside a `setTimeout(() => ..., 1100)` after
the dispense triggers.

### On Android, the receipt is not clipped by the slot

Cause: Android's rendering engine does not respect `overflow: hidden` on
`View` components that contain `Animated.View` children in some Reanimated
versions.
Solution: Wrap the receipt in an additional plain `View` with
`style={{ overflow: "hidden", height: SLOT_HEIGHT }}` and ensure the
`Animated.View` is a direct child of that wrapper. Also set
`renderToHardwareTextureAndroid={true}` on the animated child.

### Replay does not fully reset: receipt partially visible mid-animation

Cause: `controls.set("hidden")` is called, but React has not yet committed the
reset before `controls.start("visible")` fires.
Solution: Increase the debounce delay from 100ms to 150ms, or use a
`requestAnimationFrame` callback wrapping the `controls.start("visible")` call
to guarantee it fires after the DOM has painted the reset state.

### QR code not rendering in Expo

Cause: `qrcode.react` is a web-only library and will not work in React Native.
Solution: Use `react-native-qrcode-svg` (`npm i react-native-qrcode-svg`)
and render `<QRCode value="..." size={80} />` inside the receipt component.
Ensure `react-native-svg` is also installed and linked.
