# שער סליקה מאובטח ומרכז תשלומים רב-ערוצי (שב"א / Bit / 3DS)

## סקירה כללית
מיומנות זו מספקת תשתית סליקה מאובטחת רב-ערוצית העומדת בתקני PCI-DSS Level 1 ובתקן שב"א EMV J5, הכוללת ממשק משתמש ב-Liquid Glass 4.0 Pro עם כרטיס אשראי 3D אינטראקטיבי, תשלום ישיר באפליקציית Bit, סליקה ביומטרית Apple Pay / Google Pay, ומימוש ארנק RoastCoins.

### ערוצי תשלום נתמכים
1. **כרטיס אשראי 3D:** זיהוי אוטומטי של חברת האשראי (ויזה, מאסטרקארד, ישראכרט, אמקס, דיינרס), בדיקת Luhn, בדיקת תעודת זהות ישראלית, פריסה ל-1 עד 12 תשלומים ללא ריבית, ואימות 3D Secure OTP.
2. **אפליקציית Bit:** יצירת QR Code לסריקה מהירה וקישור Deep Link לנייד.
3. **Apple Pay / Google Pay:** סליקה ביומטרית בלחיצה אחת עם FaceID / TouchID.
4. **ארנק RoastCoins VIP:** תשלום באמצעות יתרת המטבעות שנצברו במועדון הקפה.

### רכיבים מרכזיים
- `lib/validations/payment.ts` - פונקציות ולידציה מתמטיות לאלגוריתם Luhn ולתעודת זהות ישראלית.
- `app/api/payments/process/route.ts` - שרת API מאובטח לסליקה והנפקת קודי אישור וטוקנים.
- `components/ThreeDCardPayment.tsx` - מודאל סליקה אינטראקטיבי עשיר ומאובטח.
