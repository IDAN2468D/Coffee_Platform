# מנוע השלמת כתובות ודרופדאון ישובי ישראל (data.gov.il)

## סקירה כללית
מיומנות זו מספקת רכיב השלמה אוטומטית ו-Dropdown אינטראקטיבי לערים ורחובות בישראל עבור עגלות קניות ותהליכי Checkout, המחובר ישירות למאגר הנתונים הפתוח של רשות האוכלוסין וההגירה ב-`data.gov.il`.

### מזהי מאגרי המידע הרשמיים
- **מאגר ישובים בישראל:** `5c78e9fa-c2e2-4771-93ff-7f400a12f7ba`
- **מאגר רחובות בישראל:** `9ad3862c-8391-4b2f-84a4-2d4c68625f4b`

### רכיבים מרכזיים
1. **שרת API פנימי (`/api/israel-addresses`):** שולף נתונים עם מנגנון Caching ו-Fallback מקומי.
2. **רכיב ממשק (`components/IsraelAddressAutocomplete.tsx`):** חיפוש מהיר, בחירה מודרכת, צ'יפים של ערים מרכזיות ומספרי בית/דירה/קומה.
3. **שילוב בעגלת הקניות (`components/CartDrawer.tsx`):** מילוי כתובת מאומתת בלחיצה אחת, שילוב קופונים ושיטות משלוח שונות.
