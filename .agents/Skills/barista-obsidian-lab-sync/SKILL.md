# מיומנות סנכרון מעבדת קפה ל-Obsidian (Barista Obsidian Lab Sync)

## ייעוד המיומנות
יצירה וסנכרון של מסמכי מחקר קפה בפורמט Markdown הכוללים YAML Frontmatter, תגיות SCA וטבלאות טלמטריה ישירות ל-Obsidian Vault ול-Google Docs.

## פרוטוקול פעולה
1. קבלת פרמטרי קאפינג (SCA Score, TDS, EY%, Grind Size).
2. עיבוד למסמך Markdown עשיר עם YAML Frontmatter.
3. יצירת קישוריות לתגיות `#coffee-research` ו-`#sca-cupping`.
4. שידור ל-MCP Obsidian או Google Docs API.
