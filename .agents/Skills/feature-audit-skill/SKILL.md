## 2. Audit & Roadmap Generation Protocol (SDD Workflow)

### Phase 1: Context Loading & Discovery
1. **State Inspection:** Read `.agents/state/ARCHITECTURE_STATE.md`, `.agents/state/SPRINTS.md`, and `.agents/state/latest.md`.
2. **Skills Mesh Scanning:** Review existing skills under `.agents/skills/` to prevent capability duplication and ensure architectural alignment.
3. **MCP Capability Review:** Inspect available tools in active MCP servers to identify innovative integration opportunities.

### Phase 2: Gap Analysis & SDD Audit
1. **Benchmark Comparison:** Compare current platform capabilities against specialty coffee industry state-of-the-art and MCP potentials.
2. **Growth Vectors:** Identify experiential and scientific gaps across IoT, sensory science, physical modeling, economic transparency, and PKM knowledge sync.
3. **Lean Execution Principle:** Eliminate redundant layers and prevent architectural bloat (Strict Zero-Bloat standard).

### Phase 3: Architectural Feasibility & Spec Validation
- **UI/UX Aesthetics:** Strictly adhere to Liquid Glass 4.0 Pro standards (120Hz GPU transforms, `backdrop-blur-2xl`, `#050404` ultra-dark theme, iridescent glows).
- **Audio & Sensory Physics:** Integrate Web Audio API (FFT spectral analysis, spatial panner nodes) and HTML5 Canvas simulations.
- **Security & Performance:** Strict `.env.local` isolation, Mongoose/Zod runtime schema validation, and Next.js 15 React Compiler optimizations.
- **Localization:** 100% Hebrew RTL (`dir="rtl"`) for all user-facing interfaces with ILS (₪) currency.

### Phase 4: Structured Roadmap Output
Generate a clean Markdown table summarizing proposed features:
`[Feature Name] | [Leading MCP / Inspiration] | [Domain Skill] | [Target Route & Component] | [Feature Summary]`
